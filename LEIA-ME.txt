FILOSINAL 2.0 — versão independente
Abra index.html no navegador. Não requer instalação de bibliotecas.
Para publicar: envie o conteúdo desta pasta para um novo projeto Vercel (framework Other, sem build, saída raiz) ou substitua os arquivos do projeto existente somente após backup e revisão. Se o projeto atual usar React/Next.js, publique como projeto estático separado ou ajuste a estrutura com o mantenedor. O endereço público depende de uma publicação autorizada. Nenhuma alteração foi feita no site original.

LIBRAS: em qualquer questão, use Adicionar vídeo na janela 9:16. A área Vídeos em Libras permite escolher um conteúdo e baixar roteiro de gravação. Os uploads locais usam IndexedDB quando disponível; são privados ao navegador. Use MP4 H.264, com rosto, braços e mãos completos. Não são traduções prontas. Para publicar vídeos, coloque os MP4 na pasta videos e edite o objeto PUBLISHED_VIDEOS no index.html, vinculando cada código ao caminho (ex.: 'q01-pergunta':'videos/q01-pergunta.mp4', 'q01-explicacao':'videos/q01-explicacao.mp4'). Identifique as alternativas pela ordem fixa A, B, C, D e pelo conteúdo. Revise com intérprete e usuários surdos.

Modo professor: seleção de questões, criação local e exportação de resultados CSV. Não há multiplayer, servidor de contas nem painel remoto. PWA: após a primeira visita online, o conteúdo estático fica disponível offline via service worker; vídeos publicados não são pré-cacheados. Vídeos locais dependem de armazenamento do navegador. Testar acessibilidade com usuários e tecnologias assistivas; não há certificação WCAG.
